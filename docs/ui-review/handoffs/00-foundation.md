Scope: `app/assets/css/**`, `tailwind.config.ts`, `nuxt.config.ts` (head, fonts,
icons), `app/app.vue`, `app/layouts/{default,legal}.vue`, `app/components/App*.vue`,

`app/composables/useButtonStyles.ts`, `app/composables/useAppNavItems.ts`.

Scores: A11y 2/4 · Perf 2/4 · Theming 1/4 · Responsive 2/4 · Anti-patterns 2/4 = **9/20 (Poor)**

Everything here is static analysis. Items marked _(verify)_ are inferred from
code and need a browser check before fixing.

## Summary

The primitives are in better shape than the score suggests: real focus trap in
`UiModal`, labelled inputs with `aria-describedby`, `role="switch"`, i18n'd
labels, local icon bundle, no `v-html`, earlier contrast work visible in
comments. The score is dragged down by what sits underneath them. There are
three colour systems and two type scales with colliding names, so every
component picks its own; the documented design system (`DESIGN.md`) describes
none of them and contradicts `PRODUCT.md`. Several token values fail AA at the
source, which is why contrast fixes keep getting made one call site at a time.
Fix the foundation and most page-level findings disappear.

## Working well — keep

- `UiModal` focus trap, Escape, focus return; `UiSwitch` semantics; `UiInput`
  label/hint/`aria-describedby` wiring and merged external ids.
- `.state-card` + `--{state}-subtle/-fg` pattern: correct in both themes with
  no `dark:` classes. This is the model for F00-01.
- Local Iconify bundle with `fallbackToApi: false`; `size-adjust` fallback
  font; pinch-zoom left enabled; `NuxtRouteAnnouncer` present.
- `aria-current="page"` on both navs; decorative icons consistently
  `aria-hidden`; no `v-html`, no `console.*`, no images without `alt`.
- Zero hardcoded `aria-label`/`title` strings outside the three noted cases.
