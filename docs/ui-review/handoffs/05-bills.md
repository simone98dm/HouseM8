# 05 — Bills

Scope: `app/pages/bills/index.vue`, `app/pages/bills/[id].vue`,
`app/components/bill/*` (14).

Scores: A11y 2/4 · Perf 3/4 · Theming 3/4 · Responsive 2/4 · Anti-patterns 2/4 = **12/20 (Acceptable)**

## Summary

The best-themed feature area: `.state-card` for errors, `--*-subtle/-fg`
tokens for chips and icon tiles, descriptive names on document actions, a
real two-column detail layout. Problems are specific rather than structural:
one wrong accessible name, a page-local toast that sits behind the mobile nav,
a detail-page action row that does not wrap, heading levels out of order, and
bill forms that restyle fields and are not forms.

## Working well — keep

- `.state-card` used for load error, delete warning and toast styling.
- Document action buttons name the file; delete confirms; list has
  `group-focus-within` so keyboard users see the actions.
- Detail grid `lg:grid-cols-3` with a clear main/aside split.
- `BillStatusBadge` and due badges carry text, not just colour.
- Lazy create/edit modals; `TransitionGroup` leave animation is
  reduced-motion aware.
