# 03 — Dashboard

Scope: `app/pages/dashboard.vue`, `app/components/dashboard/*` (4),
`app/components/bulletin/{Board,Modal}.vue`,
`app/components/house/{BillsPreview,MembersCard,RoleChangeModal,Modal}.vue`,
`app/assets/css/features/_dashboard.scss`, `components/_stat.scss`, `_table.scss`.

Scores: A11y 2/4 · Perf 3/4 · Theming 2/4 · Responsive 2/4 · Anti-patterns 1/4 = **10/20 (Acceptable)**

## Summary

Structure and loading are solid: one `h1`, skeleton that mirrors the layout,
lazy bulletin board and create-house modal, token-based cards. The screen does
not yet do the product's one job, though. PRODUCT.md asks for "€47 to Marco,
before Friday" in one glance; the dashboard opens with a greeting and four
identical stat tiles, then a five-column table that has to scroll sideways on
a phone. The members card ships a hand-built role menu that is not operable
the way its ARIA roles promise, and three modals here each restyle form
fields from scratch.
