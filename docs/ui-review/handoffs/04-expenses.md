# 04 — Expenses

Scope: `app/pages/expenses/index.vue`, `app/components/expense/*` (8),
`app/components/subscription/{PlanGate,PaywallModal}.vue`.

Scores: A11y 2/4 · Perf 2/4 · Theming 2/4 · Responsive 3/4 · Anti-patterns 2/4 = **11/20 (Acceptable)**

## Summary

The row design is good: a full-row button with a descriptive name, separate
settle/undo actions, status with text, tabular numerals, roving tabindex on
the filter. Responsiveness is achieved by rendering everything twice, though:
two lists, two filter bars, two search fields, two summary blocks, and one
confirm modal per row per list. The plan gate dims locked controls but leaves
them keyboard-operable, and the paywall is a third place with its own
hardcoded prices.

## Working well — keep

- Row = one overlay `<button>` with `viewDetailsLabel` including the
  description; secondary actions stop propagation and stay separately focusable.
- Settled/pending shown as text plus colour, never colour alone.
- `.text-numeric` tabular figures on amounts.
- Mobile search already uses `text-base` to avoid iOS zoom.
- Lazy edit/view modals.
